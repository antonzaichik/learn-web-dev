# frontend-1-practice

Итоговая практика по HTML/CSS: страница «Выбор даты и времени».

## Как открыть

1. Откройте папку `frontend-1-practice` в Visual Studio Code.
2. Откройте `index.html`.
3. Запустите через Live Server или откройте `index.html` двойным кликом в браузере.

## Что выполнено

- семантические теги `header`, `main`, `section`, `aside`, `footer`;
- стили вынесены в `styles.css`;
- для раскладки используются CSS Grid и Flexbox;
- у кнопок и ссылок есть `:hover`;
- у кликабельных элементов есть `cursor: pointer`;
- занятые слоты времени отличаются от свободных;
- выбранная дата и выбранное время имеют отдельное состояние;
- добавлена адаптация под узкий экран.
